Tetris Game - Manual Test Suite

Test Instructions

This is a manual test suite for the Tetris game. Follow the instructions below to verify each feature:

Test Cases

1. Game Initialization
✓ Verify that tetris.html loads without errors
✓ Canvas should be visible with proper dimensions (240x400)
✓ Score panel should show initial values (Score: 0, Level: 1, Lines: 0)
✓ A tetromino piece should appear at the top
2. Movement Controls
✓ Press ← (Left Arrow) - Piece should move left
✓ Press → (Right Arrow) - Piece should move right
✓ Press ↓ (Down Arrow) - Piece should move down faster
✓ Pieces should not move through walls or other pieces
3. Rotation
✓ Press ↑ (Up Arrow) - Piece should rotate clockwise
✓ Rotation should handle wall kicks (adjusting position if needed)
✓ Piece should not rotate if blocked
4. Hard Drop
✓ Press Space - Piece should instantly drop to the bottom
✓ Piece should lock in place immediately
5. Line Clearing
✓ Complete a horizontal line - Line should disappear
✓ Score should increase based on lines cleared
✓ Lines counter should increment
✓ Multiple lines should clear simultaneously
6. Scoring System
✓ 1 line cleared: +100 points × level
✓ 2 lines cleared: +300 points × level
✓ 3 lines cleared: +500 points × level
✓ 4 lines cleared: +800 points × level
7. Level Progression
✓ Level should increase every 10 lines cleared
✓ Game speed should increase with level
✓ Level display should update correctly
8. Pause Functionality
✓ Press P - Game should pause
✓ "PAUSED" message should appear
✓ Press P again - Game should resume
✓ Pieces should not move while paused
9. Game Over
✓ When pieces stack to the top, game should end
✓ "GAME OVER" screen should appear
✓ Final score should be displayed
✓ "PLAY AGAIN" button should be visible
10. Restart Functionality
✓ Click "PLAY AGAIN" button
✓ Game should reset to initial state
✓ Score, level, and lines should reset to 0, 1, 0
✓ New game should start immediately
11. Visual Elements
✓ Pieces should have different colors
✓ Blocks should have visual highlights
✓ Canvas should have proper border and background
✓ UI should be readable and well-organized
12. Collision Detection
✓ Pieces should stop at the bottom
✓ Pieces should stack on top of each other
✓ Pieces should not overlap
✓ Side walls should block movement
